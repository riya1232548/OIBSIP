# Fraud Detection

## Project Overview

This project uses machine learning to detect fraudulent financial transactions. The main challenge is the highly imbalanced dataset, where fraudulent transactions are much fewer than legitimate transactions.

## Objective

The objective is to build a machine learning pipeline that can identify fraudulent transactions while properly handling class imbalance.

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Imbalanced-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning Models

- Logistic Regression
- Random Forest Classifier

## Techniques Used

- Data exploration
- Data preprocessing
- Train-test splitting
- Feature transformation
- One-Hot Encoding
- Feature scaling
- SMOTE for handling class imbalance
- Model training
- Model evaluation

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix

## Conclusion

The project demonstrates how machine learning and SMOTE can be used to build a fraud detection pipeline for an imbalanced financial transaction dataset. Multiple evaluation metrics are used to understand the model's ability to identify fraudulent transactions.
