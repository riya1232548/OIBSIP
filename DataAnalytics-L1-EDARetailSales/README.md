# EDA on Retail Sales Data

## Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data to understand sales performance, customer behaviour, product demand, and important business patterns.

## Objective

The main objective is to explore the retail sales dataset, identify meaningful patterns and trends, and generate useful business insights through data analysis and visualization.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data cleaning
- Data exploration
- Missing value and duplicate checking
- Sales analysis
- Customer behaviour analysis
- Product analysis
- Category analysis
- Payment method analysis
- Data visualization
- Business insights

## Conclusion

The analysis helps identify important patterns in retail sales and customer behaviour. These insights can be useful for understanding business performance and supporting data-driven decisions.
