# Wine Quality Prediction

## Project Overview

This project analyzes the Red Wine Quality dataset and uses machine learning classification models to predict wine quality based on its physicochemical properties.

## Objective

The main objective is to build and compare different machine learning classification models to predict wine quality scores using features such as acidity, density, alcohol, and other chemical properties.

## Dataset

The project uses the **Red Wine Quality dataset**. The target variable is `quality`, which contains wine quality scores ranging from **3 to 8**.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning Models

The following classification models are used:

- Random Forest Classifier
- SGD Classifier
- Support Vector Classifier (SVC)

## Project Steps

1. Load the wine quality dataset
2. Explore and understand the data
3. Perform data analysis and visualization
4. Analyze the distribution of wine quality
5. Study relationships between features
6. Split the data into training and testing sets
7. Scale the features where required
8. Train multiple classification models
9. Evaluate the models using classification metrics
10. Compare the model performance

## Key Analysis

The project focuses on understanding how physicochemical properties of wine are related to its quality and how machine learning can be used to predict quality categories.

## Conclusion

This project demonstrates the use of exploratory data analysis and machine learning classification techniques for wine quality prediction. By comparing multiple models, the project shows how different algorithms can be applied to predict wine quality from its chemical properties.
